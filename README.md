- بازی دو نفره
- فیزیک برخورد توپ‌ها
- نشانه‌گیری با موس
- تعیین قدرت ضربه
- سیستم امتیازدهی
- تشخیص توپ‌های سالید و استرایپ
- قوانین پایه بازی 8 Ball
